How did you do it?

I get this question a lot from friends who notice my freedom. The short answer? I've always been intentional—I strategize carefully and design my life around my own definition of happiness.

I'm writing this blog to help mindful people build wealth—and to inspire wealthy individuals to be more mindful and intentional.

Before we begin, let's clarify something—there's a difference between being rich and being wealthy. Wealth isn't just about money or assets; it's a mindset, a way of living with freedom, intention, and lasting abundance.

As you'll soon see, there's no secret sauce—no magic formula. The question “How do I achieve financial freedom?” is much like “How do I lose weight in a healthy way?” or “How do I meditate?”—fundamental questions many of us ask in pursuit of a better life.

The answers are already out there. What truly matters is your execution. And to execute well, you need strong will, solid discipline, complete mindfulness & genuine intention to give back to humanity.

Hint: When your purpose is selfless and pure, the universe has a way of working in your favor. I can only say this based on my experience, I am not able yet to confirm scientifically.. but I am sure they are related.

Being rich vs. wealthy

The good news is, it has no direct relation to your monthly salary, but rather how you manage what you have.

In The Richest Man in Babylon, people from all walks of life—stone carvers, traders, merchants, and laborers—eventually find themselves in the same room, seeking wisdom from the richest man in Babylon. Despite their different trades and backgrounds, they all share a common desire: financial security and prosperity. The story highlights a timeless truth—wealth isn't determined by one's profession but by one's habits, mindset, and financial discipline. Those who learn to save, invest wisely, and control their spending can achieve lasting wealth, regardless of where they start.

When you earn a lot, you are rich. You are rich when you still work for money.

SvelteKit setup

Right! Now let's do the setup on SvelteKit! Good to know is that I am using `svelte v4.2.7` and `SvelteKit v2.0.0` for this current setup. First, set the correct engines:

{% highlight javascript %} // package.json { "engines": { "node": "18.x", "npm": "^9.6.7" }, } {% endhighlight %}

Then the `scripts` commands. The `start` commans is important.

{% highlight javascript %} // package.json { "scripts": { "dev": "vite dev", "build": "vite build", "preview": "HOST=0.0.0.0 vite preview --host", "start": "node build/index.js", "build:digitalocean": "npm install --production=false && npm run build && npm ci", "check": "svelte-kit sync && svelte-check --tsconfig ./jsconfig.json", "check:watch": "svelte-kit sync && svelte-check --tsconfig ./jsconfig.json --watch", }, } {% endhighlight %}

Make sure you install "@sveltejs/adapter-node": "^2.0.2":

{% highlight javascript %} npm install @sveltejs/adapter-node --save-dev {% endhighlight %}

And adjust the `svelte.config.js` accordingly:

{% highlight javascript %} // svelte.config.js import adapter from '@sveltejs/adapter-node'; import { vitePreprocess } from '@sveltejs/vite-plugin-svelte'; const config = { kit: { adapter: adapter() }, preprocess: vitePreprocess() } export default config; {% endhighlight %}

Ok that's it! Now you can commit and push the changes to the `main` branch of your GitHub.
